# AlphaGPT（imbue-bit）评估与借鉴参考

> 关联：方法论知识层（`plans/chan-knowledge-factor.md`）· 因子挖掘基建。
> 结论速览：**概念上可借鉴，代码不可直接照搬**；核心思路与本框架的 `co/ea/tot` 挖掘已等价，RL 部分本轮不建议引入。

## 1. 它是什么

[imbue-bit/AlphaGPT](https://github.com/imbue-bit/AlphaGPT) 是一个开源的**自动因子工厂**，主打 **深度强化学习（RL）驱动因子发现**，并结合大语言模型。其把「α 因子」当作**可搜索的表达式/程序空间**：

- RL 策略（策略网络）负责提议 / 改写候选因子表达式；
- 每个候选在历史数据上求值，用 **IC / Sharpe / 稳定度** 打分作为奖励信号；
- 迭代搜索，逐步收敛到高 IC 且稳健的表达式；
- 叠加 LLM，帮助生成 / 归纳更结构化的候选（跨语言、可解释）。

## 2. 与我们（QuantMind）的异同

| 维度 | AlphaGPT | QuantMind 现状 |
|---|---|---|
| 因子表示 | 表达式/程序（可求值的 α 公式） | 面板 DSL 表达式（`panel_expr`），`FactorSpec(kind/window/expression)` |
| 打分 | RL 奖励：IC/Sharpe | `co/ea/tot` 挖掘 + OOS IC / `min_abs_ic` / 复合 alpha |
| 搜索驱动 | 深度 RL 策略模型（重训练） | LLM 迭代（CoT / 进化 / 树状）+ 去冗余 + OOS 回测 |
| 数据 | 指标/行情 | A 股/期货面板（本地 Parquet） |
| 中文方法论先验 | 无专门知识层 | 本仓库「方法论知识层」：方法论种子 → KnowledgeBrief → 忠实因子 |

**关键判断**：AlphaGPT 的**表达式空间 + IC/Sharpe 稳定度评分 + 迭代搜索**三元组，与本框架 `co/ea/tot` 挖掘在概念上**已经等价**（我们都做"表达式空间寻优 + 数据打分反馈"）。其真正的增量是**用 RL 策略替代 LLM 提议**——这需要大量训练数据与算力，且针对 A 股/期货的中文方法论先验不足。

## 3. 可借鉴点（已/可吸收）

1. **表达式空间 + IC 稳定度排序** — 本框架已实现（`factor_spec_to_expression` → `panel_eval_expression` → OOS IC）。**可补**：把候选按「IC + 时间稳定度/换手」双维排序存入因子库，作为 `kb_search_context` 的成功先验（方法论知识层的消费端）。
2. **把"方法论"沉淀为表达式先验** — AlphaGPT 的种子是通用公式；本仓库的增量是**领域方法论种子（缠论/黄金分割线）→ 忠实 kind/算子**，即"带语义的 α 先验"，比纯公式更贴合用户"我说缠论3买"的诉求。
3. **失败样本回灌** — 我们 `knowledge_loop.judge_trial/summarize_experience` 已在做成功/失败模式注入，与 AlphaGPT 的奖励信号闭环同构。

## 4. 不建议本轮引入

- **深度 RL 策略网络**：训练成本高、中文期货数据难稳定收敛、可解释性差，暂不建议引入。
- **直接依赖其代码库**：面向通用因子/英文生态，移植到 A 股/期货需要重写数据层与求值器，收益有限。

## 5. 未来切入点（若要做 RL）

若后续希望引入 RL 式寻优，可**增量替换 `co`（LLM 提议）这一环**：把 `panel_expr` 表达式空间作为动作空间、OOS IC/Sharpe 作为奖励，训练一个轻量策略网络，**保留**现有的方法论种子 + knowledge_loop 闭环。届时应单独立项并先做离线仿真基准，验证相对当前 LLM 迭代的增益。
